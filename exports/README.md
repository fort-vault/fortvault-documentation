# Dated Exports

Their content has not been regenerated during documentation reorganization.

Exports are deliverables, not editable sources. Sources live under [security/iso-27001](../security/iso-27001/README.md), with [PDF tooling](../scripts/pdf/README.md) generating staging output under `output/`.

Review confidentiality, outstanding evidence, dates, and implementation claims before distribution. For a new assessment, create a new dated export instead of replacing the August package.
